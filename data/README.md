# Data Directory

## Synthetic Data (`synthetic/`)

Generated by `src/data_generator.py` for prototype demonstration.

**Format:** CSV with columns:
- `timestamp` - Time in seconds from sequence start
- `ax, ay, az` - Accelerometer readings (m/s^2)
- `gx, gy, gz` - Gyroscope readings (rad/s)
- `gt_speed` - Ground-truth forward speed (m/s)
- `gt_yaw_rate` - Ground-truth yaw rate (rad/s)
- `gt_x, gt_y` - Ground-truth position (meters)
- `gt_heading` - Ground-truth heading (radians)

**Coordinate Convention:**
- X = forward (direction of travel)
- Y = left
- Z = up

**WARNING:** Synthetic data is for demonstration only.
Results do not represent real-world accuracy.

## Using Real Data

To use real IMU data, provide CSV files with at minimum:
- `timestamp` - in seconds
- `ax, ay, az` - accelerometer (m/s^2)  
- `gx, gy, gz` - gyroscope (rad/s)
- `gt_speed` - ground-truth speed (m/s) for training

For inference-only (no ground truth needed), only timestamp + IMU columns required.

Supported datasets for future integration:
- IO-VNBD (Oxford Inertial Odometry)
- RoNIN
- Custom Android app recordings
